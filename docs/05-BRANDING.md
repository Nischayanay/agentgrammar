# agentgrammar — Branding & Positioning

## Positioning statement

**For** developers using AI coding agents (Claude Code, Cursor, Codex)
**who** want expert-level results across design, code, review, migration, and media,
**agentgrammar** is a curated online library of skills and plugins your agent installs on demand.
**Unlike** copy-pasting prompt packs or cloning repos,
agentgrammar lets the agent itself discover and pull exactly the skill the task needs — one tool,
every IDE.

## The category we own

"**Skills for agents.**" Not prompts, not templates — installable, curated capabilities an agent
requests at runtime. We want "agentgrammar" to become the verb: *"just agentgrammar it."*

## Name & meaning

- **agentgrammar** = the grammar (rules, structure, vocabulary) that gives agents competent behavior.
- Always lowercase in product surfaces (`agentgrammar`), like a command you'd type. This also makes
  the tool-call chip read naturally in a prompt.

## One-liners (use everywhere)

- "The library of skills your AI agent installs on demand."
- "Give your coding agent expert skills — design, code, review, migration, media."
- "One tool. Every AI IDE. A skill for every job."
- "Stop copy-pasting prompts. Let your agent install the skill."

## Voice & tone

- **Precise, not hypey.** Mirror the existing frameworks' voice: concrete, output-oriented, a little
  blunt about failure modes ("AI coding agents are useful until they are not").
- **Developer-native.** Show, don't sell — code blocks, real prompts, real diffs.
- **Confident minimalism.** Short lines. No fluff. Every claim testable.

## Visual identity (starter direction)

| Element | Direction |
| --- | --- |
| Logotype | lowercase `agentgrammar`, mono or geometric sans (JetBrains Mono / Inter) |
| Mark | a bracket / caret motif — `⟩` or `⌘`-adjacent glyph suggesting a callable command |
| Chip | the in-IDE tool chip: small icon + `agentgrammar`, mirroring the Supabase-chip pattern |
| Color | dark-first (matches IDE dark themes). Base near-black `#0B0F14`; one electric accent |
| Accent | pick ONE: electric violet `#7C5CFF` or signal green `#3DDC84` (green echoes the Supabase chip) |
| Badges | keep the existing shields style (`#111827`) for README consistency |

Recommendation: **near-black + electric violet** to differentiate from Supabase green while keeping
the same "branded tool chip" recognizability.

## Logo/chip icon brief

A single glyph that reads at 16px in the composer chip: a caret/bracket `⟩` or a small
"assembling blocks" mark. Must work monochrome (IDE chips are often single-color). Deliver SVG +
PNG @1x/2x, light and dark variants.

## Messaging pillars

1. **On-demand, not copy-paste.** The agent installs the skill itself.
2. **Curated, so it's trustworthy.** Every skill vetted against a quality bar.
3. **One tool, every IDE.** Claude Code, Cursor, Codex — same snippet.
4. **Free to start.** Build your agent's toolkit at no cost.

## Naming conventions for content

- Skills: verb-or-noun, kebab-case id, Title Case name (`design-system-builder` → "Design System
  Builder").
- Domains: `design`, `code`, `media`. Categories: `ui-ux`, `frameworks`, `review`, `migration`,
  `motion-graphics`, ...

## What to avoid

- Don't call them "prompts" or "templates" — dilutes the category.
- Don't over-promise autonomy ("your agent does everything"). Promise *capability*, not magic.
- Don't lead with pricing — it's free; lead with the demo.
